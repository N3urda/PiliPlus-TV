# 电视端使用与验证

应用会根据 Android TV 的系统类型或 Leanback 能力启用电视界面。手机和平板继续使用原有布局；电视默认使用横屏、深色主题、侧边导航、较大的卡片与文字，打开视频后播放并进入全屏。已保存的播放、主题和字号偏好优先于默认值。

## 遥控器

| 场景 | 操作 |
| --- | --- |
| 浏览、设置和弹窗 | 方向键移动焦点，确认键选择，返回键返回 |
| 全屏播放画面 | 确认键播放 / 暂停，左右快退 / 快进 |
| 打开播放菜单 | 上、下或菜单键 |
| 播放菜单 | 方向键选择播放、选集、画质、字幕、弹幕、倍速、收藏、定时关闭等操作 |
| 返回顺序 | 收起播放菜单 → 退出全屏 → 返回列表 |

焦点使用黄色轮廓标识，列表会随焦点滚动。直播保留播放、弹幕、定时关闭及重试入口，不提供快进和倍速。

## 首页与输入

- 推荐页增加搜索、观看记录、收藏、稍后再看、追番、订阅和电视设置入口。
- “继续观看”展示最近未看完的视频 / 番剧，恢复对应分集与进度；切换账号后刷新，无痕模式下隐藏。
- 电视登录默认展示二维码，可刷新过期或加载失败的二维码，也可进入其他登录方式。
- 搜索支持系统语音服务；设备没有语音服务时，可以使用手机扫码输入或原有键盘。
- 手机与电视需要在同一局域网。手机输入窗口提供一次性地址，仅接收搜索文字；电视确认后搜索，窗口关闭或 5 分钟后地址失效。路由器的访客网络隔离可能阻止连接。

## 播放与更新

Wi-Fi 和有线以太网均使用宽带画质 / 音质 / 解码偏好，移动网络继续使用原有蜂窝网络偏好。

“电视设置”保留常用播放开关，并提供“更多设置”访问原有功能。更新源是 `N3urda/PiliPlus-TV` 的正式 GitHub Release，按设备 ABI 选择 APK，在应用内下载、检查文件大小及可用的 SHA-256 校验值，再打开系统安装器。首次安装更新可能需要允许安装来源，返回后再次选择“安装”。覆盖更新需要相同包名、签名及可升级版本；调试包使用独立包名，不支持正式包覆盖。

## 自动化检查

使用 `.fvmrc` / `pubspec.yaml` 指定的 Flutter 版本，并应用仓库现有 Flutter 与 material_ui 补丁后运行：

Android 构建使用 AGP 9.1.1，以满足 [Android 官方对 API 37.0 的工具版本要求](https://developer.android.com/build/releases/about-agp#api-level-support)。

```sh
flutter pub get
flutter test --no-pub
flutter analyze --no-pub
flutter build apk --debug --target-platform android-arm64 --no-pub
```

`test/tv/` 覆盖遥控器按键分发、焦点与双向滚动、弹窗焦点恢复、网络选择、观看进度和分集去重、安装包选择、二维码失败恢复与并发刷新，以及手机输入鉴权、中文传输、长度限制和过期关闭。`PILIPLUS_TV=true` 编译定义可在非电视环境辅助检查布局；正式 Android TV 自动识别，无需此定义。
