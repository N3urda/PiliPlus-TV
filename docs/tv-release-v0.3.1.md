# PiliPlus TV v0.3.1 测试版验证记录

## 本版内容

- 影院风格视频首页：大屏 6 列卡片，遥控器选择视频后直接播放，返回保留浏览位置。
- 热门视频、视频搜索和翻页；登录后可在“动态”查看关注 UP 主本人新投稿的视频。
- TV 图片缓存上限 48 MiB、120 张；搜索结果按可见区域创建卡片，缩小缩略图解码尺寸，减少内存占用。

## 安装包

- 源码版本：`0.3.1+4`；Android 包名 `com.n3urda.piliplustv`，最低 Android API 24。
- 使用 `flutter build apk --release --split-per-abi --target-platform android-arm64 --no-pub` 构建。发布文件命名为 `PiliPlus-TV-v0.3.1-arm64-test.apk`，约 20.9 MB；`aapt` 和 APK 内容均确认只有 `arm64-v8a` 原生库。
- APK 使用当前 TV 分支的固定本地测试签名，证书 SHA-256 为 `fad6b4417e67a8742a332d1e15ce2dc79a2f33b45b3c853058380cf08da94d06`。已通过 `apksigner verify`，并成功覆盖安装在先前的 v0.3.1 测试包上。v0.3.0 本地包签名相同、版本码为 3，可以覆盖升级；更早的测试包若签名不同，安装前需卸载，卸载会清除账号数据。

## Android TV 模拟器回归

在 1920×1080 Android TV 模拟器上覆盖安装发布 APK，并检查：

1. 首页首屏 6 列视频及遥控器焦点；连续 4 次进入真实视频播放、返回原卡片。返回后的 PSS 分别约为 204、201、223、215 MiB；播放时随视频内容在约 253～315 MiB 间变化。
2. 热门列表取得真实视频；未登录动态页显示登录入口，扫码页成功获取二维码。
3. 搜索 `music` 得到真实结果；方向键到“加载更多”并载入第二页；选择结果直接播放，返回后仍在搜索结果中。
4. 搜索第二页时发送 Android `RUNNING_LOW` 内存通知；应用进程保持运行，页面继续显示。

模拟器的软件解码开销和实体电视不同。关注动态的登录后内容、75 寸电视观看距离与实体电视的硬件解码效果仍需安装到设备后验证。
